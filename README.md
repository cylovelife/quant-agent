# quant-agent — 每日波段低买投资助手

跨市场（A股 / 港股 / 美股 / 场内ETF / 场外基金）波段低买筛选 Agent。
每日自动运行：抓行情 → 多因子评分 → 历史回测 → 生成报告 → 次日复盘迭代权重。

> ⚠️ 仅供研究学习，不构成投资建议。

## 快速开始

```bash
# 手动运行（完整模式，约 1~2 分钟）
python run.py

# 快速模式（减少回测数量）
python run.py --quick

# 只跑部分市场
python run.py --market cn,etf

# 跳过昨日复盘
python run.py --no-eval
```

依赖安装：`pip install requests pandas numpy curl_cffi`

## 目录结构

```
run.py              主控入口（支持 --quick / --market / --no-eval）
config.json         市场开关、粗筛过滤参数、基金观察池
params/params.json  策略参数（因子权重/阈值/回测参数），每日自动迭代并留存版本
src/fetcher.py      多源行情抓取（腾讯+东财+天天基金，含降级与限流熔断）
src/indicators.py   技术指标（RSI/MACD/BOLL/ATR/量比等）
src/strategy.py     粗筛 + 六因子低买评分模型
src/backtest.py     单标的低吸策略回测（次日开盘买、持有5日、-5%/+8%止盈止损）
src/evaluate.py     昨日推荐复盘 + 权重在线更新（滚动相关性微调）
src/report.py       Markdown + HTML 报告生成
reports/            每日报告（report_YYYY-MM-DD.md/.html）
state/              每日推荐存档、滚动收益样本 outcomes.csv、行情缓存
logs/               运行日志
universe_fallback.json  东财限流时的降级核心标的池（ETF/港/美股）
```

| 数据 | 主源 | 降级源 |
|---|---|---|
| A股列表 | 腾讯财经排行接口（跌幅榜Top400） | — |
| ETF/港/美股列表 | 东财 clist（成交额头部2页） | 腾讯批量行情+核心池 |

内置三层网络容灾：直连 → 系统代理 → curl_cffi 浏览器指纹；东财请求失败自动写 30 分钟熔断标记切降级源，避免拖垮整次运行。

## 策略与迭代机制

1. **评分**：布林下轨贴近度、RSI 超卖甜点区(25~40)、缩量回踩、60日线上方保护（防坠落刀）、MACD 柱拐点、近20日适度回撤，六因子加权求和。
2. **回测**：每只候选回测近一年"低吸信号"（信号次日开盘买，持有5日或触发止盈止损），报告展示胜率/场均收益/最大回撤。
3. **迭代**：每日复盘昨日推荐的次日实际收益 → 滚动样本存 `state/outcomes.csv` → 满 20 笔后按“各因子得分与实际收益的滚动相关性”微调权重（**贝叶斯式：用相关性的 t 值调制学习率——不显著则保守、显著则激进，显著负相关因子直接压到下限**，防止小样本过拟合），版本化保存到 `params/`。

## 自动化诊断与可复现性（参考微软 R&D-Agent-Quant 优化）

> 文章《R&D-Agent-Quant：面向量化投研的多智能体框架》强调：可验证的因子构建、统一可复现评测、自适应探索-利用调度、全流程留痕。我们为纯规则量化落地了其中不依赖 LLM 的四项：

- **因子共线诊断**（验证单元“因子去重”思想）：每日基于入选候选池截面计算 6 因子两两相关，标记 |r|≥0.7 的冗余对（如 RSI↔趋势），防止权重叠加放大单一维度。报告见「因子健康度」章节。
- **统一可复现评测**：回测在胜率/场均/回撤之外新增 **信息比率 IR、Calmar、年化收益 ARR**（信号数≥5 才统计）；因子层新增截面 **IC / Rank IC**（评分与回测场均收益的截面相关），量化“分数越高表现越好”的单调关系。
- **贝叶斯式权重更新**（分析单元“探索-利用自适应”思想）：用相关性 t 值调制学习率，报告展示每因子相关性、t 值与显著性（✅/⚠️），使“为何调权”可解释。
- **运行留痕 manifest**（规范单元“全流程留痕”思想）：每次运行写 `state/run_manifest_YYYYMMDD.json`，快照版本/权重/相关性/显著性/Top 候选/市场概览，便于可复现复盘。

## 每日自动运行

由 WorkBuddy 自动化驱动：每个交易日 17:30（A股收盘后）自动运行并输出当日报告；
昨天的推荐会被自动复盘，收益与权重调整体现在"复盘与迭代"章节。
