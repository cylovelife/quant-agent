# 虚拟投资账户验证方案

2026-10-26。按用户本轮澄清，当前主目标是：**事前设定虚拟本金，按策略模拟后续投资，
用账户现金、持仓和每日净资产的持续变化验证结果。** 不需要提供真实账户或投入真实资金。
本方案补充并修正[执行计划](usability_revision_plan.md)的当前验证目标。

## 一个完整的账户试验

1. 启动前登记虚拟本金、币种、启动日期／时点、可交易范围、策略版本、资金分配与风险规则、成本假设和比较基准。
   用户已确认启动本金为人民币50,000元；这不表示账户已经启动。
2. 账户初始只有虚拟现金；持仓为空。启动时点之后才允许产生和执行新模拟订单，不能用已知后续行情补造启动前持仓。
3. 策略使用当时可获取的信息决定买卖或持有，模拟撮合按事前规则确定价格、数量、费用和未成交原因。
   没有满足条件的标的时保留现金，不为让试验“有动作”而强行投资。
4. 每个交易日记录可用／占用现金、证券数量、持仓估值、费用、已实现／未实现损益和账户总资产。
   价格、数量、现金、公司行动与计价币种的口径必须一致。
5. 按日、月及累计观察净收益、回撤、风险暴露、换手和成本，并与同起点、同本金、同资金流口径的基准账户比较。
   账户配置或策略切换保留版本、生效日期和原因，不重写旧交易或事后重置本金。

一个组合账户只有一份总本金；不同策略共享时须明确额度，不能把每个策略都当作拥有整份本金。
并行独立账户可以用于策略对照，但须单独编号、各自记账，其资金不能再相加冒充同一个账户的收益。

## 每日核对的资金关系

在统一币种并按已登记的现金流时点结算后：

- 期末现金来自期初现金、模拟买卖净额、费用、分红及事先登记的虚拟入提款。
- 每个持仓数量来自前日数量、模拟买卖及拆并股等数量事件。
- 账户净资产 = 现金余额 + 持仓市值；占用资金须按登记口径避免重复计入。
- 累计损益 = 当前净资产 - 初始虚拟本金 - 累计净入金；有外部资金流时另列时间加权及资金加权收益。
- 每笔订单、模拟成交、现金流水和每日估值均可回查；缺价不把持仓清零，重复运行不重复成交或扣费。

**每日净值包含尚未卖出的持仓浮盈亏。** 任务2中“标签未成熟不计复盘”仅限制训练／统计样本，
不意味着要等一笔交易平仓或满5天才更新账户资产。

## 三类验证分别记录

| 类型 | 使用方式 | 能支持的结论 |
|---|---|---|
| 构造数据测试 | 人工给定价格、订单、费用、分红和资金流 | 资金守恒、边界行为及重复运行是否正确 |
| 历史账户回放 | 从过去某日以固定本金，按当时可见信息顺序模拟 | 历史区间内的账户表现；若方案看过该区间再修改，该结果属于开发证据 |
| 前瞻虚拟账户 | 事前冻结配置，从启动时点起跟随后续新行情推进 | 实际留档期间的模拟资金曲线和执行一致性；记录时长及尚未成熟的样本如实报告 |

后续行情用于模拟成交和估值，不代表真实账户成交。暂时只有构造测试或历史回放时，
不能写成已经开展前瞻模拟。没有券商持仓、真实生活资金或真实账户费率，不妨碍设定明确假设启动虚拟试验。
数据与算力的实际支出预算仍与虚拟投资本金分开管理。

现金／数量账本 → 公司行动及虚拟现金流 → 每日净值与基准。
任务7拆成以下逐项验收单元，每完成一个单元仍先验证并征求用户意见：

| 单元 | 交付 | 验收 |
|---|---|---|
| 7a | 给定本金、币种与启动时点的虚拟账户初始化 | 初始现金等于登记本金，持仓为空；同一账户不能重复注资，不能执行启动前订单 |
| 7b | 基于事件逐日推进、估值和输出资金曲线 | 买卖／费用／分红／入提款可对账；含空仓和浮盈亏；漏跑可顺序补结算，重复运行幂等 |
| 7c | 同起点基准及小规模前瞻试验启动材料 | 同额、同起点比较；冻结策略／成本／风险／基准与记录方式；启动日期及首个可交易时点明确，不能倒填 |

完整实验身份、搜索／调权门禁仍在任务9完善；任务7c至少保留足够复现此账户的冻结配置、代码与数据来源，
不等论文、比赛、Qlib或所有研究步骤完成才开始积累虚拟账户记录。

试验内按已冻结规则执行模拟订单，无需逐笔另行请求批准；策略／资金规则变更按试验配置和用户要求留档处理。
