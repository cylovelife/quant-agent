# 确认信号逐日跟踪与优先级变化

## 范围与实施顺序

1. 新增 `research_tracking.py`：固定观察规则、逐日核验、前一交易日排名比较、SQLite台账。
2. `daily_research.py` 在原有研究事务内登记/核对，并将结果随run_id归档；重复输入只读既有结果。
3. 主报告显示四项状态、证据日期/数值与排名变化；明细保留完整规则、来源和历史。
4. 离线测试覆盖确认/回落/低点破坏/缺失/修订、跨日排名、重复执行与失败回滚；实际运行日报。

## 固定语义

- 仅从真实发布的研究优先清单建立观察，不按历史行情回算虚构旧日推荐。
- 同一轮入选期间固定原观察日高/低点、参数、历史输入、登记时刻；连续入选不每天重置。
  退出清单后结束该轮观察；以后重新入选才建立新轮次，旧轮次保留。
- 只检查原观察日之后、且登记时已不可见的完整日线：盘前/盘中登记可从当日收盘起核对；
  盘后登记不追认当日已经可见的收盘。登记日与行情交易日分开保存。
- 四项分别核验：收盘突破原高点；MACD柱>0；收盘>动态MA60；回踩日
  （收盘<=前收）量比处于[0.4,0.9]。量比窗口沿用登记时参数。
  非回踩日不误判量能失效，保留最近适用日的结果并注明。
- 待确认：未曾满足；已满足：最近适用日满足；已失效：曾满足后不再满足。
  单项条件回落后允许再次满足，但保留首次满足日期与逐日核验记录。
  任一后续日线最低价<原观察低点使整轮观察终止为失效，不自动复活；保留首次满足/失效日。
- 另有“暂不可判定”：缺行情、未推进、历史价格修订、历史覆盖不足等；不假报满足/失效。
  已知低点破坏的终止记录不会因缺数据而被抹去。
- 成交量修订按量能依赖单独检查，不能阻断可信的价格、MACD、MA60和低点失守检查；
  成交额不参与四项条件，变更只留审计。量能的有限取整兼容与阈值保护见下方修订记录。
- 日内重跑与输入/代码修订不增加交易日证据。来源历史发生修订时不直接比较旧qfq阈值。
- 排名按相同观察池、股票/ETF各自前3与原有62分阈值；比较行情序列中严格前一交易日
  的留档，缺该日记录则不跨越缺口冒充“较昨日”。给出新增/退出/上升/下降/持平和得分差。
  数据缺失不伪装成退出；参数口径变化单独提示。
- 此层仅跟踪技术研究条件，不修改生产评分、不做自动买入、不算策略准入验证通过。

## 持久化与恢复

在现有 `ledger.db` 新增会话、观察轮次、核验三张表。自然唯一键和原有
`BEGIN IMMEDIATE` 保证单写者/重复执行安全；所有写入与研究记录同一事务提交或回滚。
历史输入与规则留在观察轮次，核验结果按观察id、行情日、run_id追加，原研究run不回写。
同日记录允许不同输入版本，比较时取前一交易日最后一次实际留档。

## 2026-10-27：按信号依赖保护历史修订

### 实际影响与原因

证券ETF国泰（512880）原观察日为2026-10-26，登记于当天18:34，原低点1.007。
10月27日快照与冻结观察历史共有299根日线；OHLC和成交额全部一致，291根成交量不同，
最大差0.5手、最大相对差约4.98e-8。差异与已核验的新浪精细成交量和腾讯整手表示兼容；
不因此声称任何数值相近的数据都必然只是取整。

用原暖启动历史和修订成交量分别计算，10月27日量比为：

- 原输入：1.0643268188319854。
- 修订输入：1.0643268152469005；绝对影响约3.59e-9。
- 每根历史量取新旧两值的最小／最大值形成包络，量比区间为
  [1.064326810420825, 1.064326823658061]，全部高于0.9。
- MACD和MA60没有变化。该日最低价1.000已经低于原低点1.007，应该终止本轮观察。

原实现先对全部OHLCV／成交额做统一比较，任一字段变化立即返回四项不可判定，
因此无关的量精度差异遮蔽了真实的低点失守。本次保留价格修订保护，拆开量额依赖。

### 可执行语义

1. 原历史任一OHLC字段实质变化，仍按既有 `rtol=1e-10, atol=1e-10` 检查并暂停四项，
   不拿修订后的价格去碰撞旧复权阈值。缺行情、交易日缺口和历史覆盖不足的保护不变。
2. 历史成交量变化不暂停价格、MACD、MA60；可信的后续最低价低于原低点时，优先终止
   整轮，即使量能仍不可判定，也不能遮蔽已知风险。
3. 仅当共同历史的量均有限且非负、一方全部为整手、每根差值绝对值不超过0.5手时，
   将其标为 `rounding_compatible`。这只是有限表示差异的候选，不是来源认证或直接忽略。
   其他量修订标为 `material_revision`，量能暂停，其余可信条件继续。
4. 对兼容候选逐根取新旧成交量的最小／最大值，再计算此前N根均量上下界和量比区间。
   不是只比较两套完整序列，防止正负取整差异相互抵消。区间全在[0.4,0.9]内才满足；
   全在同一侧才认定不满足；跨边界、历史不足或任一均量边界为零时，仅量能不可判定。
   这里没有把相对容差放大，也不使用价格的半单位容差。
5. 历史成交额不进入这四项计算，修订只留痕。`revision_review`逐字段记录变化根数、
   最大绝对差及量修订分类；量能附 `value_range` 与判断依据，主报告说明依赖规则，明细展示修订审计。
6. 原观察高低点、参数、历史和登记时刻不改；已记录的首次满足日期在不可判定时保留，
   非回踩日沿用最近适用日。已终止轮次不复活，不放宽生产评分或策略准入。
