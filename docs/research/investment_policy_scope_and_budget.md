# 首期范围与研究预算登记

任务1的交付是 [一页虚拟账户政策模板](investment_policy_template.md)、首期工程研究范围和本页预算表。
当前验证目标按[虚拟投资账户方案](paper_account_validation.md)执行：预设虚拟本金，以后续策略产生的账户资金变化验证效果。
虚拟试验参数及实际研究支出预算待确定，不要求提供真实账户、生活资金或券商持仓。
依据：[最新执行规划](usability_factor_review_2026-10-26.md)、[分步计划](usability_revision_plan.md)。

## 首期范围

沿用本地SQLite、现有adapter及冻结快照，以日线输入、日／周／月级决策为边界。
周／月聚合只使用截止日已经出现的行情，不借未来周期末日期补齐。

| 工作线 | 首期范围与固定产物 | 当前边界 |
|---|---|---|
| 价值观察 | 从已有A股观察池中选择投资者熟悉的少量企业，形成一页价值备忘录 | 具体企业待选择；不把“在观察池中”当作投资者已经理解或认可企业 |
| ETF趋势 | 只选一个ETF，事先固定趋势、波动调整、调仓／退出和成本，做独立模拟 | ETF及规则待选；任务13实施，不在本任务创建交易规则或指定购买标的 |
| 六因子研究 | 冻结现行评分与候选范围作为基线，股票与ETF分别评测 | 沿用当前6只A股＋6只ETF的研究观察池；扩池须形成新的实验版本；不足以代表全市场 |
| 账户核算 | 构造数据检查正确性后，启动给定本金的前瞻虚拟账户，持续记录现金、数量、费用、现金流、净值和跨策略风险 | 完整资金账户按任务3–7优先实现；五万元为已确认的虚拟启动本金，账户尚未初始化或运行 |

工程研究先围绕现有A股／场内ETF数据推进；虚拟账户在启动前固定证券范围和分配规则。
已有港股、美股、场外基金入口保留，首期不据此扩张研究任务。
复杂模型、自动搜索、多市场扩张和比赛提交按分步计划后续验收。

当前配置事实以 [config.json](../../config.json) 为准：

- `local_research.universe.cn` 与 `.etf` 各6只；池内名单是数据观察范围，不是已经建立的虚拟持仓。
- `markets` 包含 `cn`、`etf`、`hk`、`us`、`fund`，不等于首期每个市场都已完成核算与验证。
- `longterm.benchmark` 当前为 `510300`，这是现有程序配置；虚拟账户和三类策略的比较基准在试验启动前固定。

两份文档均为人工填写／审阅材料。本任务不增加配置键或加载器，`run.py`尚未接入政策与预算校验。
首期范围也未改写现有运行配置；后续接入时，应显式区分构造测试、历史回放和已启动的前瞻虚拟账户。

## 政策字段口径

未填、未核验与不适用分开标注；未填不解释为0、无限额或默认同意。不适用须写原因。

| 填写项 | 需要说明的口径与一致性条件 |
|---|---|
| 虚拟本金与启动时点 | 本金、币种、账户编号和启动时点明确；不要求真实资金来源；启动前没有虚拟持仓，初始化幂等 |
| 虚拟入提款 | 金额／日期／允许变更规则事前登记；未知金额不能被当成可用现金，不事后补资修饰收益 |
| 市场、证券与流动性 | 列明市场／证券／币种；流动性阈值须有单位、窗口及来源；账户费率和交易限制按适用证券核验 |
| 策略额度与风险上限 | 各资金分配及储备不能超出本金；以账户净值为分母时说明计价与日期；策略内上限不能绕过账户合计限制 |
| 暴露合并 | 同标的跨策略先合并；ETF穿透明确成分日期／来源／覆盖率，避免直接持仓与穿透结果双重计数；覆盖不足时不下“风险已满足”结论 |
| 现金储备 | 明确可用于交易的现金、近期提款及最低储备；储备不能再分配到策略预算 |
| 风险触发与责任 | 明确触发指标／阈值／观察窗口／动作／责任人／复核时限；Agent不能自行放宽；数据质量异常暂停新增建议，已有持仓风险另行记录 |
| 账户与策略基准 | 明确证券或组合标识、权重／再平衡、币种／汇率、分红／费用；同起点、同本金、同现金流比较，不按结果换基准 |
| 成本与成交 | 模拟佣金、最低收费、税费和滑点分别列单位、单边／双边、适用市场及证券、依据和版本；可采用明确登记的假设，不要求真实账户费率；净收益须说明所用假设 |
| 策略归属与退出 | 每笔持仓登记价值／趋势／量化归属及对应退出条件；改属有新决策记录，原策略损益继续留档 |
| 收益与复核 | 策略比较用排除虚拟入提款影响的时间加权收益；资金时点另列资金加权收益；月／季／年复核记录试验版本和修订原因 |

## 研究预算登记

数据、算力等实际研究支出预算独立于虚拟投资本金，不能用五万元虚拟资金替代实际支出额度。
每月只选一个主要研究问题；每个正式实验再登记自己的指标、数据、切分与预算。
本页为登记模板，当前没有任何已确认的费用或搜索额度。

| 登记字段 | 待填内容 |
|---|---|
| 预算周期与负责人 | 起止日期、登记人、确认人及日期：待填 |
| 本期唯一主要问题 | 可被否定的假设、继续／终止标准：待填 |
| 人工工时 | 本期总工时上限、单次实验工时上限：待填，单位小时 |
| 数据费用 | 本期总上限、数据源／授权范围：待填，金额及币种 |
| 算力与模型费用 | 本期总上限、单次运行上限：待填，金额及币种；本地运行注明本地，不自动视为无成本 |
| 运行资源 | 单次最长墙钟时间、并发上限、CPU／内存或设备预算：待填，注明单位 |
| 搜索与重试 | 本期候选／参数组合上限、单次实验上限、失败重试上限：待填；比较双方预算分配：待填 |
| 实验评价 | 主要指标、最小有用效应、风险限制、成本压力、训练／验证／封存测试、随机种子计划：待填 |
| 成本记录 | 工时、数据费、算力／模型费、候选／失败／重试数、实际耗时的记录位置：待填 |
| 停止与恢复 | 超时／超费／超次数、数据时点错误或测试失效的退出点：待填；恢复条件、剩余额度和确认记录：待填 |

候选搜索计入已查看结果的方案和失败试验；重试不增加独立市场样本，但占用实际时间、费用和重试预算。
工时、数据费、算力费分别统计，合计费用用已登记的币种与汇率，不将异币金额直接相加。
对照方法获得事前规定且合理可比的调参机会；预算调整保留旧值、生效时间和原因，不追溯抹去失败试验。

正式搜索或付费运行须先登记相应预算。预算待填期间，任务2等工程开发仍可用构造数据与本地小规模验证推进；
不以此启动无上限循环、付费采购或实际账户操作。预算达到上限即保留结果并停止该搜索，
不额外换窗口或另起名字规避限额。预算、试验次数与运行状态的程序门禁由后续任务9及21接入。

## 当前缺项与可继续范围

| 尚缺输入 | 直接影响 | 可独立继续的工作 |
|---|---|---|
| 启动时点、现金流及观察窗口（虚拟本金人民币50,000元已确认） | 尚不能初始化确定版本的前瞻账户；不需要真实生活／应急资金 | 构造现金流、持仓及净值案例 |
| 模拟市场／证券／流动性和杠杆规则 | 尚不能确定虚拟账户允许的订单范围 | 现有A股／ETF范围内的隔离研究与接口开发 |
| 模拟策略／行业／单标的／总暴露、现金储备和风险动作 | 尚不能运行已冻结风险配置下的虚拟策略 | 以测试政策验证合并风险与触发逻辑 |
| 账户及三类策略基准、模拟费率与汇率来源 | 不能报告指定假设下的净超额或认定收益可比 | 显式标明假设的成交、成本及基准样例 |
| 具体熟悉企业、单一ETF、对应规则和退出条件 | 不能把观察池名单当成已选策略 | 价值备忘录模板、共用标签与核算契约 |
| 虚拟账户尚未启动 | 没有前瞻资金曲线或已发生的模拟成交可评价 | 从空仓初始状态开发与验证，无需导入真实持仓 |
| 研究预算、负责人／确认日期和主要问题 | 不能开始正式搜索或付费实验 | 文档、契约、确定性本地工程验证 |

虚拟试验参数确定后，核对一致性并冻结启动版本；模拟订单按该版本运行，不逐笔另行请求批准。
当前模板交付不等于账户已启动，也不等于程序已执行资金与风险门禁。
