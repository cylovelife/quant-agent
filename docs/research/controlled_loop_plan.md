# 最小受控研究闭环

本轮只支持构造数据，以既有长期五维权重方案为候选；不训练模型，不接入真实封存数据或前瞻账户。

1. 冻结验证文件、测试文件摘要、日期、候选全集、成交规则、资金与预算；登记时不打开测试文件。
2. 每个验证候选通过 `ExperimentRegistry.run_attempt` 运行，独立子进程只接收该阶段数据，超时终止；每次账户评估创建临时账本。
3. 以扣费后的期末模拟净资产排序，平分时按预声明顺序；仅全部候选受控验证成功且未超预算才锁定。
4. 锁定后的一次测试尝试同时评估选中候选与预声明 default 基准，现金基准为初始资金。失败消耗测试机会，重复请求仅回读。
5. 保留原成交、记账、实验预算、单次测试与生产准入门禁；结果始终 `promotion_allowed=false`、`independent_new_samples=0`、`total_return=null`。

验证先覆盖闭环、提前读取拦截、手工结果拒绝、失败回读、输入漂移、下一开盘执行和成本对账，再运行项目规定离线回归与构造行情集成测试。源码在独立 worktree 修改，不提交或推送。

边界：进程隔离提供阶段数据分离与超时控制，不是恶意代码的操作系统沙箱。候选仅允许内置确定性权重，没有用户代码执行接口。构造数据声明不能证明外部数据真实性，真实数据准入另行设计。
