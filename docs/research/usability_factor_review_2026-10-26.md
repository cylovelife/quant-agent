# quant-agent 投资与研究执行规划

2026-10-26

**建设一套服务个人长期资本积累、能够接受公开检验的投资研究系统。** 投资端覆盖长线价值、趋势和简单量化，支持日常决策与年度规划；研究端通过强基线、可复现实验、论文和外部比赛检验方法。以日、周、月频为边界，暂不做高频。

投资端对资金、风险和决策质量负责；研究端对结论的真实性、可推广性和复现成本负责。两者共享数据与核算，分别验收。任何研究结果进入个人账户前，都要经过对应市场、成本和资金约束的检验。

**项目判断与近期取舍**

现有行情存储、数据适配、快照、规则评分和观察跟踪，足以支持个人研究与事前留档。现有证据尚不足以确认六因子具有稳定超额收益，也不足以证明组合可交易性或自动迭代优于固定策略。功能能运行、回测盈利、方法有效是三种不同结论。

优先建设可信账本、公平评测和可追踪决策。首期投资端采用“少量熟悉企业的价值观察＋流动性合适的 ETF 趋势模拟”；研究端围绕六因子开展一个明确的对照实验。这样可以覆盖三类方法，同时控制个人维护成本。复杂模型、自动因子搜索和多市场扩张，等基线与核算可靠后再做。

投资原则沿用 [invest 策略笔记](/Users/cylove0330/Documents/notes/leon/invest/00-投资规划与方法/策略.md) 中的风险预算、决策记录与复盘要求；研究纪律参考 [量化工程路线图](/Users/cylove0330/Documents/notes/leon/invest/02-量化研究/量化策略研究与开发工程师路线图_2026-07.md)。下文为目标与验收标准，不表示相关能力均已实现。

**一份投资政策，约束所有策略**

由投资者填写并确认一页投资政策，作为账户的最高约束。Agent 可以提出修改建议，不能自行提高风险额度。

| 必须确定的事项 | 可执行定义 |
|---|---|
| 资金与期限 | 可投资本金、未来年度入金与提款、独立保留的生活及应急资金、各笔资金的使用期限 |
| 投资范围 | 允许的市场、证券类型、币种与流动性要求；首期建议现金支持的多头策略，不使用杠杆 |
| 风险预算 | 单标的、行业、策略与合计暴露上限；流动性储备；触发复核、暂停新增或减仓的条件及责任人 |
| 收益比较 | 事前指定可投资的账户基准，以及各策略的基准；统一币种、分红与费用口径，不事后挑选对手 |
| 决策权限 | Agent 提供证据、估值与交易建议；投资者确认实际交易。研究候选不能自动替换账户策略 |

风险管理同时考虑本金永久损失、市场价格波动、流动性和被迫卖出。止损与回撤限额是应对规则，不能保证成交价格或最大损失。多个策略持有同一股票，或 ETF 间存在重复持仓时，按账户合计暴露管理。

年度规划先安排资金用途与承受能力，再确定资产及策略预算。年度复盘分别计算排除入提款影响的时间加权收益、反映个人资金时点的资金加权收益，并解释收益来自市场上涨、选股、择时、配置还是风险放大。短期收益排名不替代长期论据检验。

**三类策略，各有收益逻辑和退出纪律**

| 策略 | 要检验的收益来源 | 必须形成的决策依据 | 退出或复核条件 |
|---|---|---|---|
| 长线价值 | 企业持续创造现金、合理再投资，以及买入价格低于审慎估值 | 商业模式、竞争优势、资本回报、治理与资本配置、财务安全、估值区间 | 投资论据被证伪、价值下修、价格已充分反映价值、存在更好机会或账户约束触发 |
| 趋势 | 价格持续性能够覆盖震荡损失与交易成本 | 事前固定的趋势规则、波动调整、持有与调仓周期、成本和失效情形 | 规则反转、风险预算触发或数据／执行失效；不得亏损后改称长期投资 |
| 简单量化 | 可重复的统计关系在样本外和扣成本后仍有增益 | 明确特征、收益标签、股票池、排序／交易规则和独立测试 | 超过预定失效条件、费用侵蚀优势、数据分布变化；不得靠连续调参掩盖失败 |

价值研究每家公司形成一页投资备忘录：业务如何赚钱、优势为何可持续、正常化盈利与可分配现金、资本配置记录、保守／基准／乐观估值、当前价格隐含的预期、最强反方观点、证伪条件和下一次复核日期。安全边际随业务可预测性、负债和估值不确定性变化，不统一套一个折扣。

长期评分中的质量、成长、现金流、财务安全和估值可用于筛查。成长要与再投资回报一起判断；低估值要排查盈利衰退与治理风险；金融企业采用行业适配指标。宏观首先进入情景与组合风险分析，其选股增益另行验证。公司价值不能由六个财务分数完整替代。

三类策略分别记账、分别归因，组合层分配风险。同一持仓在建仓时明确策略归属；改变归属需要新的决策记录，保留原策略的实际损益。价值持仓不因技术指标超卖而自动加仓，趋势持仓也不因估值便宜而取消退出纪律。

**六因子的定位与处置**

六因子表达“趋势背景中的短期反转”假设，可以作为研究基线。五项主要来自价格，不能视为六个独立收益来源；布林、RSI 和 20 日跌幅合计约占 59% 权重。分段函数和因子分布会改变实际排名影响，名义权重不等于风险贡献。[参数配置](/Users/cylove0330/Documents/tech/mydev/quant-agent/params/params.json)

| 因子及配置权重 | 保留的含义 | 首要验证 |
|---|---|---|
| 布林位置 23.94% | 相对波动区间的位置 | 与 RSI、跌幅是否重复；下跌趋势中高分是否造成持续亏损 |
| RSI 22.99% | 短期涨跌强弱 | 超卖区间是否稳定；删除它后净收益与换手如何变化 |
| 量能 13.44% | 交易活动变化 | 联合价格方向与流动性验证，不能直接把缩量解释为抛压消失 |
| 趋势 12.14% | 中期方向和交易背景 | 比较连续特征与交易过滤；评分中的加分项不能充当风险限制 |
| MACD 变化 15.29% | 动能变化 | 避免接近零的分母放大噪声；比较波动率归一化后的稳定表达 |
| 回撤 12.21% | 价格回落程度 | 明确 20 日收益与距峰值回撤的区别，统一名称与定义，检查评分断点 |

实验先比较“单一反转特征”“反转＋趋势／波动控制”“完整六因子”，再逐项删除因子，识别扣成本后的增量。股票与 ETF 分开，所有方案共用正确的计算、成交和资金核算。先冻结评分函数和候选范围，再做时间切分；不得在测试集上反复寻找最佳权重。

保留因子的条件是稳定、可解释且值得其复杂度的增量。若简化方案表现相当，采用简化方案；若均无可靠优势，六因子保留为观察工具。因子数量和当前权重均不设保留义务。

**一套可信的评测与账户底座**

工程沿用本地 SQLite、已有 adapter 和 `src/`、`tests/` 布局。Qlib 通过适配层接入，不重写已可复用的行情与账本能力。先建立以下契约，再扩大模型规模。

| 契约 | 最低验收条件 |
|---|---|
| 当时可见的数据 | 保存来源、发布时间、抓取时间、修订版本和当时股票池；财报不得早于披露日使用，退市与停牌样本不得无故消失 |
| 正确的价格与回报 | `qfq` 用于短线评分，`raw` 用于估值分位，保持隔离；投资收益单独核算分红、拆并股与持仓现金流，不能把 raw 涨跌直接当总回报 |
| 一致的交易语义 | 信号时点、可交易时点、成交价格、持有终点一致；计佣金、税费、滑点和未成交，约束依据证券及市场逐项配置 |
| 可核对的净值 | 每日现金、数量、价格、费用与净值相符；覆盖首笔亏损、空仓、分红、入提款、停牌和跳空；回撤从完整净值序列计算 |
| 独立的时间检验 | 按日期整体切分，剔除标签跨界样本；预处理只在训练集拟合；调参用验证集，最终测试封存 |
| 可追踪的实验 | 固定数据、代码、环境、股票池、特征、标签、成本、切分、种子及搜索预算；失败试验也登记，同一快照重跑不增加证据 |

前复权历史会修订，保存今天的快照不能证明历史当时可见。无法取得历史版本或历史成分时，应标明研究限制，不能声称完成无偏历史检验。数据过期或质量检查失败时暂停生成新增交易建议；已有持仓仍按既定风险规则处理，不能因数据缺失被静默清空。

研究结果依次经过离线评测、冻结版本、前瞻模拟和账户适配复核。前瞻阶段先检验数据、信号与执行的一致性，再等待收益标签成熟；短期跑通不算收益验证。沿用现有调权门禁，增加候选对现行策略的独立比较、回退条件与留档，不能由历史 IC 单独触发升级。[项目边界](/Users/cylove0330/Documents/tech/mydev/quant-agent/AGENTS.md)、[确认跟踪规范](/Users/cylove0330/Documents/tech/mydev/quant-agent/docs/research/confirmation_tracking.md)

**与 Qlib 和前沿方法如何比较**

Qlib 是研究框架与模型集合。竞争目标应写成“在指定数据、任务、成本和预算下，某项方法较某个强基线改善多少”。首组对照采用简单规则、Ridge 和 Qlib Alpha158＋LightGBM；只有研究问题需要时再增加深度时序模型。[Qlib 官方项目](https://github.com/microsoft/qlib)、[Alpha158＋LightGBM 配置](https://github.com/microsoft/qlib/blob/54355232463878d2eebb91fe0ee5fa7fa1f5976c/examples/benchmarks/LightGBM/workflow_config_lightgbm_Alpha158.yaml)

保留两种协议。**官方复现协议**固定上游版本、数据和配置，报告复现差异；**个人可投资协议**让所有方法使用同一信息集、可交易股票池、收益目标、成本和风险约束。两种结果分别列示，不拿不同持有期的 IC 或不同成本下的收益直接排名。

| 要证明什么 | 必须设置的对照 | 主要评价 |
|---|---|---|
| 策略有投资价值 | 买入持有、等权、简单价值或趋势，以及冻结六因子 | 扣成本收益、相对基准超额、回撤、尾部损失、换手及容量敏感性；同风险条件下比较 |
| 预测方法有增量 | 同特征的规则、Ridge、LightGBM；完整特征管线另列 | 按日期计算的排序相关性（Rank IC）、分层收益、衰减与跨期稳定性 |
| 自动研究有效 | 固定策略、滚动重训、预算匹配的搜索及适配的研究 Agent | 每单位研究成本取得的样本外效用、无效切换、错失机会、运行成功率和信息违规 |

每次正式实验事先确定一个主要评价指标、最小有用效应、风险限制和搜索预算。按多个不重叠测试窗口报告结果，采用保留时间相关性的区块抽样等方法估计区间，披露多重搜索。多个随机种子、同日多只股票和重叠持有期不算独立市场样本。所有方法获得合理且可比的调参机会。

测试结果一旦用于修改方案，该段数据就成为开发数据，需要新的最终测试。LLM 参与历史研究时，需单列模型可能见过历史事件的污染风险；前瞻记录从冻结方案后的新数据开始。

**论文与比赛：围绕一个可被否定的主张**

首选研究问题：**在数据修订、市场变化和有限搜索预算下，基于独立证据的策略升级规则，能否减少错误切换，同时保留扣成本后的投资效用？**

先完成文献查新，定义升级规则与适用条件，再决定是否值得立项。策略晋级、时序验证与模型选择均有既有研究；修复 bug、增加快照、组合指标或让 Agent 生成代码，都不足以单独构成方法创新。[RD-Agent(Q)](https://arxiv.org/abs/2505.15155) 已研究因子与模型联合优化，应作为相关工作；其论文结果须与本地复现分开。

论文最小实验包包含三组检验：

- **机制对照**：使用同一候选集，比较固定策略、定期更新、直接选择验证最优和提出的升级规则；逐项移除机制，识别增量来自哪里。
- **现实扰动**：区分真实数据修订与人工缺失／延迟扰动，检验不同市场阶段和合理成本变化；只在人工场景有效，结论就限于该场景。
- **预算与泛化**：在至少两类适配任务上比较，计入人工干预、失败试验和计算成本；自动研究对照使用相同信息与预算。

错误切换按事先指定、随后成熟的未来窗口评价，升级决策只能读取当时已知数据。同时报告错失有效升级的代价，并与“永不升级”比较。更少切换但长期效用明显受损，不能算成功。没有稳健增量时，发布复现或负结果报告，不为凑论文继续挑窗口。

外部评测首期只选择一个平台。预测与泛化可先评估 Numerai 的无质押参赛路径，官方允许不质押仍获评分；其成绩验证平台规定的预测任务，不能替代 A 股个人账户净收益。[Numerai FAQ](https://docs.numer.ai/numerai-tournament/faq) 自动研究能力成熟后，再评估 [Quant-Arena](https://lab.einsia.ai/quant-arena/) 等端到端基准；具体资格、数据授权及提交规则以接入时核验为准。记录官方得分、相对名次、参与规模和已成熟轮次，不把重叠轮次当独立证据。

论文交付以一个明确主张、强基线、消融、效应区间、失败案例和可复现实验包为标准；比赛交付以官方回执及持续前瞻评分为标准。发表、获奖、盈利与工程可靠性分别记账。

**个人使用与 Agent 分工**

| 节奏 | 固定产物 | 决策动作 |
|---|---|---|
| 每日盘后 | 一页变化简报：数据截止、持仓风险、论据变化、触发条件与费用影响 | 维持、复核或提出交易；无新增信息时不制造操作 |
| 每月 | 账户对账、策略归因、配置偏离、交易成本、研究失败清单 | 再平衡候选、暂停失效研究、确定下月唯一主要实验 |
| 每季 | 企业论据与估值更新、策略证据复核、情景压力测试 | 调整观察名单，按既定规则决定候选晋级或退出 |
| 每年 | 投资政策、现金流计划、基准、年度归因与下一年预算 | 根据实际资金用途和证据修订配置，解释决策错误与机会成本 |

Agent 负责收集证据、给出反方论据、组织实验和解释结果；可验证代码负责数值、时点、资金与风险约束。研究 Agent 不能修改评测器、访问封存测试或绕过账户限制。自动循环设时间与费用上限、检查点和失败退出，记录模型、提示词及工具版本。先建立人工提出假设、程序执行与记录的基线，再测自动化是否节省时间或提高研究产出。

**执行顺序与停止条件**

时间为规划窗口，按验收结果推进。数据条件和投入不足时缩小范围，不降低证据标准。研究预算独立于投资本金，开始实验前登记工时、数据费、算力和可接受的最大试验次数。

| 阶段 | 集中交付 | 验收后再推进 |
|---|---|---|
| 第 1–2 周：定义与核算 | 一页投资政策；统一信号、成交、标签和净值；固定数据与实验身份 | 构造案例跨模块收益一致，费用／分红／入提款可核对，未来数据扰动不改变过去决策 |
| 第 3–6 周：最小可用系统 | 个人持仓与风险视图；价值备忘录模板；一个 ETF 趋势模拟；六因子、Ridge、Qlib 基线 | 账本可对账；日常输出可追溯；官方复现与个人协议分开；基线可重复运行 |
| 第 7–12 周：确定研究方向 | 六因子消融；趋势与反转独立测试；文献查新与升级规则试验；一个外部平台的本地适配 | 识别增益与失败原因；决定保留、简化或终止假设；测试段与搜索记录完整 |
| 第 4–6 月：独立验证 | 冻结候选的前瞻模拟；预算匹配强对照；复现包与论文初稿；条件满足时外部提交 | 主结果可重跑；外部成绩有官方记录；只有成熟标签进入评价；个人策略经过账户适配复核 |
| 持续至年度 | 连续决策日志、资金归因、前瞻结果与策略淘汰记录 | 解释何处有效、何处失效及付出的成本；一年结果不外推为永久能力 |

投资者负责资金政策与实际交易，工程负责数据和账目正确性，研究负责假设、协议及结论。即使由同一人承担，也分开记录决策。每月只推进一个主要研究问题；新增模型必须替代或解释现有实验，不能无限增加试验清单。

三条停止条件贯穿执行：**账目或信息时点错误，暂停性能结论；复杂方法没有足够增量，保留简单方案；研究失去独立测试或超过预算，停止搜索并报告现有结果。** 个人端交付可核对、可持续使用的决策记录，研究端交付能被他人复核、也允许被否定的结论。
