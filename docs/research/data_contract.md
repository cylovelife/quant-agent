# 任务3：数据版本、可见性与质量契约

日期：2026-10-26。实现与离线验证完成，待本步意见；任务4未开始。
本步为后续虚拟账户提供数据准入和追溯基础，没有初始化本金或验证策略收益。

## 已实现的行为

- `src/data_quality.py` 集中处理数据来源、抓取时间、数值版本及准入检查。
  `store.load_kline` 和 `LocalData.get_data` 通过 `DataFrame.attrs.data_provenance`
  保留元数据，原有返回列保持兼容。周／月聚合另留底层输入观察与版本。
- 行情快照格式升级为2，保留来源、逐日抓取时间及价格版本；仍可校验和镜像格式1。
  `snapshot_id` 包含元数据；`price_dataset_id` 只包含标的身份、日期和行情数值。
  同价重抓记为 `provenance_update`，不会被当作价格修订或增加观察交易日；数值修订产生新版本，旧快照不覆盖。
- 保存实际观察／指定的标的池，包括未加载的代码。主流程登记来源、观察时间、可能经过缓存的事实，
  上游抓取时间与发布时间未知时留空；本地研究明确为调用方指定池。不能据此推断历史成分。
- `run.py` 在新信号归档前冻结数据检查与快照。重复／乱序日期、无效OHLC、负数或非有限量额、
  末日零量、缺少已观察交易日、滞后／未收盘数据、缺失来源／有效抓取时间或复权身份不符，
  均阻止对应标的新信号及新增登记；报告候选同步过滤。所有候选被拒绝时不冻结空信号文件，允许数据恢复后重新检查。
  主流程的新鲜度另按当前已完成日线截止日检查，不能靠陈旧参考行情把检查日倒退；
  非当前已完成日线日只复核既有信号，不拿当前池补造历史首次信号。
- A股／ETF主流程以510300日线为参考；缺失参考或其质量／来源不满足条件时暂停准入。
  这是观察到的参考交易日，不是官方交易日历。缺口与零量只标为未知原因，不虚构停牌或节假日。
- 已有持仓即使退出候选池，仍独立加载并检查。数据不可用时标记 `unavailable`，
  保留原状态、成交、观察价格与风险记录，不补造平仓收益。首次历史回放也受同一检查约束。
  历史收益复盘在主流程开启质量门禁，不把来源缺失或坏价的成熟标签写入训练结果。
- 财务回放只接受实际披露日期；缺失／无效日期和法定截止日代理不参与回放。
  缺少准确盘中时间时，披露日当天不使用，从次日才可用；不再退回报告期末日期。
- qfq请求不再静默接受raw响应，raw请求也不再接受qfq响应。
  qfq源响应含解析失败的行时留下缺陷标记；异常响应不作为健康行情写入缓存。

`new_signal_allowed` 同时要求数据可用及属于本次池；`data_usable` 只表示数据条件，
用于核验已有持仓，避免“退出候选池就停止跟踪”的错误。检查无法冻结时暂停新增及价格结算，原账本保留。
已有首次信号归档保持不变；数据恢复通过检查后可继续核验，不能重写历史成交来适应修订数据。

## 产物与限制

主流程下次实际运行时写入本地 `state/data_contract/`：

- `snapshots/<snapshot_id>/`：内容寻址行情与清单，读回时校验完整性及元数据一致性。
- `check_<record_id>.json`：包含本次时间、池、质量决策和快照指针的检查记录。
- `latest.json`：原子替换的最新检查指针。信号文件另存所用数据契约，研究台账保留其自身快照指针。

结构不可解析或身份不符的序列不能进入规范快照，检查记录仍保留拒绝原因及 `excluded_from_snapshot`。
不通过排序、去重、填价或猜测停牌来修好坏输入。快照目录未被发布前的写入失败不产生成功指针。

这只保存**本地观察并冻结的版本**，不等于完整历史时点数据库：

- 行情准确发布时间、历史股票池、历史退市／停牌覆盖仍未知。
- 抓取时间不是发布时间，也不是历史数据首次可见时间。旧SQLite无时区时间原样保留，不补猜时区。
- 旧格式1没有抓取元数据；可以验证文件完整性，不能因此取得新信号准入。
- 以前存入的行情是否曾发生复权口径替代不能追溯认证；本次修复只阻止后续适配器继续替代。
- 财务修订版本、旧raw文件来历及公司行动覆盖尚不完整。按披露日期过滤的历史回放仍为描述性研究，
  不能标为完整无前视或总回报验证。
- 本地研究可保留带来源缺口的描述性历史观察，报告单列新模拟信号数据条件；
  观察交易日计数不等于独立统计样本，既有调权和晋级门禁继续生效。
- 本次准入覆盖A股／ETF的v2模拟信号；长期价值观察、港美股和场外基金旧流程不属于虚拟账户成交入口。

订单、真实可成交价格、证券单位、费用和滑点由任务4实现；现金、数量和净值依赖后续任务。
不能用本步qfq标签价格直接扣虚拟现金并当作真实股数。
