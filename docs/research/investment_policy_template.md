# 一页虚拟投资账户政策模板

状态：**模板结构已认可**；实际试验参数及其有限适用范围见[冷启动记录](cold_start_2026-10-27.md)。目标：用后续行情驱动的虚拟账户资金变化验证策略。
下表为通用空白模板，实际账户以冻结的试验登记为准。

| 事项 | 投资者填写或确认 |
|---|---|
| 资金与计价 | 初始虚拟本金：按试验登记确定；基准币种：人民币；初始现金等于本金，持仓为空 |
| 启动与模式 | 历史回放或前瞻模拟：待定；启动日期：待定；具体登记时点：待定；首个可交易时点：待定；前瞻试验不倒填 |
| 虚拟现金流 | 预设入金／提款金额及日期：待定；允许变更的规则：待定；不能事后注资掩盖损失 |
| 观察窗口 | 日／月／累计评价周期：待定；是否允许自动策略切换及其事前规则：待定 |
| 允许范围 | 市场：待填；证券类型：待填；币种及汇率来源：待填；流动性要求及度量窗口：待填 |
| 策略与额度 | 价值／趋势／量化各自的资金或风险额度：待填；首期现金支持多头、不用杠杆的方案：待确认 |
| 单标的上限 | 占账户净值的上限：待填；跨策略同标的合并计算 |
| 行业上限 | 行业暴露上限：待填；行业分类及来源：待填 |
| 策略与总暴露 | 各策略暴露上限：待填；账户合计暴露上限：待填；ETF重复持仓计入口径：待填 |
| 流动性储备 | 最低可用现金或储备比例：待填；近期提款覆盖期限：待填 |
| 风险动作 | 复核条件：待填；暂停新增条件：待填；减仓条件：待填；责任人及复核时限：待填 |
| 账户基准 | 可投资基准的标识及构成权重：待填；分红／币种／费用及再平衡口径：待填 |
| 策略基准 | 价值：待填；趋势：待填；量化：待填；各自分红／币种／费用口径：待填 |
| 成交成本 | 分市场、证券与虚拟账户的模拟佣金／最低收费／税费／滑点假设、依据及版本：待定 |
| 决策权限 | 试验内按冻结规则生成并执行模拟订单；策略／资金规则变更留档；不连接真实账户或执行真实交易 |
| 退出纪律 | 建仓时确定策略归属；价值按论据／估值复核，趋势按冻结规则退出，量化按失效标准复核；具体条件：待填 |
| 复核与归因 | 每日记录现金、数量、费用及含浮盈亏的净值；月度／累计对账与归因；有虚拟入提款时分列时间加权与资金加权收益 |

账户合计暴露按同标的跨策略及ETF穿透结果复核，不能把缺失成分当作没有重叠。
风险触发条件是应对规则，不代表可保证的成交价格或损失上限。
涉及策略归属或政策变化时，记录原因、生效日期和旧版本，保留原策略实际损益。

- [ ] 确认此版本用于虚拟账户试验，记录启动时点。确认人：待填；确认日期：待填。
